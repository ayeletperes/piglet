# `plotAlleleCluster`

Plotting the dendrogram of the clusters


## Description

Plotting the dendrogram of the clusters


## Usage

```r
plotAlleleCluster(x, y = NULL)
```


## Arguments

Argument      |Description
------------- |----------------
`x`     |     The GermlineCluster object. See [inferAlleleClusters](#inferalleleclusters)
`y`     |     NULL. not in use.


## Value

A plot of the allele clusters dendrogram
