# `GermlineCluster-class`

Output of inferAlleleClusters


## Description

`GermlineCluster` contains output from [inferAlleleClusters](#inferalleleclusters) function.
 It includes the allele cluster table, the germline set hierarchical clustering,
 and the threshold parameters.


## Usage

```r
list(list("plot"), list("GermlineCluster,missing"))(x, y = NULL)
```


## Arguments

Argument      |Description
------------- |----------------
`x`     |     GermlineCluster object
`y`     |     not in use. missing.
